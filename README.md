# 墨砚 · iOS

参考相邻 `inkstone` 桌面项目实现的原生 SwiftUI 移动端。支持 iOS / iPadOS 17 及以上，使用 Swift Markdown / cmark-gfm 解析 Markdown，数据保存为 UTF-8 Markdown 文件。

## 打开与运行

1. 使用 **Xcode 16 或更新版本**打开 `Inkstone.xcodeproj`。
2. 选择 `Inkstone` scheme 与 iPhone / iPad 模拟器后运行。
3. 真机运行时，在 Signing & Capabilities 中选择自己的开发团队，并按需修改 Bundle Identifier。

也可以一条命令构建、安装并启动模拟器：

```sh
./scripts/run-simulator.sh 'iPhone 17e'
# iPad：
./scripts/run-simulator.sh 'iPad mini (A17 Pro)'
```

不传设备名称时优先选择已启动的 iPhone，存在多个匹配时需指定名称或 UDID。脚本会自动使用 `/Applications/Xcode.app`，无需全局切换 `xcode-select`；显式设置的 `DEVELOPER_DIR` 优先。兼容旧版 Simulator 与 Xcode 27 的 Device Hub。

```sh
open Inkstone.xcodeproj
# 完整 Xcode 环境：
xcodebuild -project Inkstone.xcodeproj -scheme Inkstone \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

仓库包含生成后的工程，不需要安装 XcodeGen 或 CocoaPods。添加 App 源文件后运行 `python3 scripts/generate_project.py` 更新工程。

## 已实现

- 本地笔记库；通过系统「文件」选择外部文件夹，持久化访问书签。
- 可见的最近／文件夹／书签入口；记住浏览位置；新建直接输入，首次自动保存前可填写名称和选择目录。
- 文件夹选择式移动、独立重命名、引用影响与链接更新预览、批量移动和删除。链接更新预览供手动核对，暂不自动改写正文。
- 与 PC 端兼容的 WebDAV 手动双向同步：笔记、附件、相对路径、修改、移动与删除；冲突保留副本。
- 全文搜索（多个关键词同时匹配）、命中片段高亮与正文段落定位、书签、最近修改排序。
- 默认富文本编辑，直接修改排版后的正文；工具栏支持标题、加粗、斜体、删除线、列表、待办、引用、代码、链接和表格，支持撤销／重做。保留源码编辑、结构化 Markdown 阅读、图片粘贴和自动保存。
- Wiki 双链、别名、反向链接和可跳转大纲；缺失目标可直接创建，同名歧义仍会提示。
- 本地相对路径图片、照片插入、附件导入与 Quick Look 预览；字号与行距设置。
- 宽度至少 1000 pt 时采用目录／列表／正文三栏；分享扩展保存文字和网页链接至共享收件箱。
- UTF-8 Markdown 导入与系统文件导出；同名导入拒绝覆盖。
- 停止输入 450 毫秒后直接保存 Markdown；新建、已有笔记均自动保存，外部修改冲突时阻止覆盖。
- 历史／已删除分类，恢复后直接打开副本；含附件和空目录的 ZIP 备份；可选保留期和手动清理。
- 所有恢复均创建副本；保存和删除前比对原文，检测外部修改或删除。
- 浅色 / 深色外观跟随系统；中文界面与辅助功能标签。

## 与桌面配合

在设置中选择包含桌面笔记的文件夹，或导入桌面 `.md` 文件。iCloud Drive 等文件提供商负责设备间传输；本应用只协调本机文件访问并重新扫描文件。外部库不会写入桌面 `.inkstone` 元数据；移动端的历史、书签独立存放。

打开笔记后，如果另一个应用修改了原文，点击保存会提示冲突。可通过笔记菜单「另存副本」保存移动端内容，再重新打开原文件核对。前台激活和下拉刷新会扫描最新内容；编辑器不会自动替换正在编辑的正文。

### WebDAV 同步

1. 在 PC 端「设置 → 云同步」填写一个已存在的 WebDAV 目录，先同步一次。
2. 手机端「设置 → WebDAV 云同步」填写**完全相同的目录地址与用户名**，输入密码，测试连接后点击「立即同步」。地址填写专用 `inkstone/` 目录的父目录，与 PC 端一致。
3. 保存配置后默认启用「自动同步」。前台启动或返回、笔记保存/移动/删除/导入后会安排同步；打开笔记、设置或列表操作弹窗时暂缓，关闭后执行。仍可点击「立即同步」。PC 端需完成自身同步才能交换最新内容。

自动同步合并约 3 秒内的连续修改，两次自动尝试至少间隔 30 秒；前台空闲时每 2 分钟检查云端。失败后按 30 秒、1/2/4/8 分钟递增重试，最长间隔 15 分钟；错误显示在同步设置中，不反复弹窗。自动同步开关按笔记库保存，只使用已保存且与输入框一致的连接配置。关闭自动同步后仍可手动同步。

两端共用 `inkstone/manifest.json` 与 `inkstone/objects/<SHA-256>`，支持清单 v1/v2 并保留维护代次。服务器须支持强 ETag、条件 PUT 和 MKCOL。旧 `inkstone-v1` 目录会阻止同步，需按 PC 端指引迁移。远端普通 Markdown 文件夹不会自动导入。

双端同时修改时，本地内容保留在原路径，远端内容另存为 `名称 (云端冲突 摘要).md`；修改与删除冲突保留修改。同步前版本可在手机「恢复」中查看。下载校验、条件发布、设备基线与本地提交恢复记录用于防止过期覆盖及中断后的误删除。云端清单丢失或维护代次回退会停止同步。

配置按手机笔记库保存，密码保存在此设备钥匙串。推荐 HTTPS；HTTP 仅适合可信网络。空文件夹、隐藏文件、书签、设置和历史不上传。附件会原样同步；本地图片可在阅读页展示，普通附件通过 Quick Look 预览（单个本地预览/插入上限 32 MB）。同步单文件上限 128 MiB，笔记阅读/编辑上限仍为 8 MiB。同步按文件处理并暂存整个库，需足够的本地磁盘空间；大库与真实服务商尚需验收。自动同步仅在前台运行；退到后台会取消前台调度，不保证完成在途传输，不提供系统后台定时同步。恢复前台后按调度规则继续，沿用同步中断恢复机制。

本地二进制同步备份保留在应用私有恢复目录 `.sync/<账号标识>/backups/`，每条记录含 `content` 和原路径 `path.txt`；暂未提供附件备份恢复界面。恢复记录不自动清理，也不会上传。文件提供商的跨设备冲突和传输时机仍由提供商管理，不能把本机文件协调视为跨设备事务。

## 保存与恢复

新笔记和已有笔记均在停止输入约 450 毫秒、输入法组词完成后自动写入 Markdown；返回、切换笔记或进入阅读时立即保存，也可点击顶部勾号手动重试。首次自动保存采用填写的标题，没有标题时使用唯一的“未命名”文件名；后续正文修改不会自动改名。空白新建页未输入时不会创建文件。保存失败会提示并保留编辑器中的内容，遇到外部修改冲突时暂停自动保存，可另存副本。应用不再生成本机草稿；旧版草稿在打开笔记库时迁移为同目录下带“恢复”标记的 Markdown 副本，不覆盖原文件。退出到后台也会尝试保存，强制终止前尚未完成的写入不保证保留。

历史和已删除正文存放在应用私有 Application Support 中，**不会同步到桌面，也不能代替备份**。卸载应用会删除这些记录。可选择 30／90／365 天保留期并确认清理过期历史和已删除记录；清理不会自动运行。整库 ZIP 导出包含笔记、附件及空目录，不含私有恢复记录与密码，当前总大小上限 128 MB、条目数少于 65,535。

本地笔记位于应用 Documents/墨砚笔记，支持系统文件共享。外部文件夹采用安全作用域书签与 `NSFileCoordinator`；笔记读写在 `Vault` actor 上串行执行，文件写入使用原文比对和原子替换。扫描跳过隐藏文件与符号链接，单篇笔记上限 8 MB，无法读取的文件会在设置显示原因。

## 阅读与兼容范围

编辑默认使用离线打包的 ProseMirror 富文本编辑器（WKWebView），文件仍保存为 UTF-8 Markdown，现有同步与历史流程继续使用。点击右上角「… → 切换到 Markdown 源码」可以编辑原始语法，也可以切回富文本；应用记住此选择。工具栏可横向滑动，支持表格增删行列、列表缩进、任务勾选、链接与 Wiki 双链；链接输入框提供库内笔记路径建议。图片通过原有笔记库附件读取器加载，粘贴图片写入附件后插入到原选区。

打开富文本不改写文件；未修改的顶层块保留原始 Markdown，修改过的块按 Markdown 规则输出。frontmatter、引用定义和 HTML 作为只读块保留，需要改动时使用源码模式；HTML 不执行。富文本撤销记录在当前编辑会话内有效，切换笔记或重新打开编辑器后重置。中文输入法组词期间暂停保存和格式操作，切换视图及保存前读取最新编辑事务。大文档的富文本性能及真机输入法仍需按验收清单验证。

富文本资源已经提交，Xcode 构建不需要 Node.js 或在线下载编辑器。修改 `RichEditor/` 后运行 `cd RichEditor && npm ci && npm run build`，将构建后的 `Sources/InkstoneCore/Resources/RichEditor/` 一并提交。模型测试运行 `npm test`；WebKit 交互测试运行 `npx playwright install webkit && npm run test:browser`。依赖锁定于 `RichEditor/package-lock.json`，第三方许可随编辑器资源一起打包。

阅读采用 `swift-markdown` 文档树与原生 SwiftUI 渲染，支持 ATX/Setext 标题、多行段落与硬换行、嵌套强调/删除线/行内代码、普通及引用式链接、有序/无序/嵌套列表、多段及嵌套引用、任务、表格对齐与横向滚动、围栏及缩进代码块、分隔线。代码块显示语言标签并支持复制。支持库内相对路径图片和 HTTP(S) 图片加载（失败时显示替代文字）、Wiki `[[文件夹/笔记|别名]]` 与库内相对 `.md` 链接；任务勾选保留原文件换行格式。大纲与 Wiki 索引共用同一解析器。不再提供标签分类；已有正文和 frontmatter 内容保持原样。

尚未实现：桌面实时预览模式、数学公式、代码语法高亮、嵌入笔记、完整 YAML、Wiki 链接标题片段自动跳转、链接自动更新、桌面历史格式和后台云同步。上述原始 Markdown 保留不变，可在源码模式编辑。大纲可点击定位；搜索定位到包含命中的顶层正文块，不改变 Markdown 原文。HTML 按文本展示，不执行；嵌套在链接/强调中的图片仅显示替代文字。未闭合的 frontmatter 按普通 Markdown 解析。

构建时 SwiftPM 会下载锁定的解析器依赖（见 `Package.resolved`）；文字解析与排版离线可用，网络图片需要联网。第三方许可随 InkstoneCore 资源打包。

## 日常记录流程（2026-11-07）

首页展示最近／文件夹／书签、搜索和新建。点新建直接进入编辑器；名称和目录可在首次自动保存前填写。移动和重命名分开，目录选择器支持现场新建文件夹；批量操作逐篇执行，失败保留已完成结果并提示。

首页与编辑页提供同步状态入口，区分写入文件、待同步、暂停和错误；已同步表示上次成功检查的结果，不代表后台持续在线。同步期间可阅读已加载正文的只读快照，附件、任务修改和跳转不可用；编辑仍需要结束同步后重新打开。

分享扩展将文字与链接放入 App Group 的独立收件箱；下次打开主应用或回到前台时导入当前笔记库的 `收件箱/` 目录。导入失败保留共享副本，不直接访问外部库。主应用与扩展需使用同一开发团队，并为二者配置 `group.com.inkstone.mobile` App Group；模拟器未签名构建不能证明真机扩展签名和跨进程分享正常。

宽窗口使用三栏；编辑期间调整窗口大小不会重建编辑器，关闭笔记后重新选择布局。外接键盘支持 Cmd+N、Cmd+S，iOS 编辑器保留系统选区和撤销。
