# 移动端验收

所有交互验收使用示例库副本，不使用个人笔记。核心测试不替代原生平台验收。

## 自动检查

`./scripts/check.sh` 运行核心 Swift Testing 用例，编译共享 SwiftUI 页面，验证 plist 和工程文件语法。完整 Xcode 环境另外执行 README 中的 iOS simulator build 命令。

## 2026-10-07 本机验证

- 15 项核心回归通过，含外部库丢失后不重新创建目录的检查。
- 共享 SwiftUI 界面在 macOS 26.5 SDK 下编译通过；工程及 Info.plist 语法通过。
- 在 `.build/preview-vault` 隔离目录启动原生 macOS 共享页面预览，验证新建子文件夹笔记、粘贴中文/emoji/组合字符、Cmd+S 保存、阅读模式任务勾选并保存。
- 直接修改隔离目录中的磁盘文件后，编辑器保存出现冲突提示；未保存正文仍在编辑器中，保留草稿关闭成功。
- 检查磁盘正文，确认勾选为 `- [x]`、桌面并发正文未覆盖、草稿与历史独立保存。
- 原生预览是共享视图的 macOS 宿主，不能视作 iOS 验收；粘贴测试也不等同于中文输入法组合输入测试。

## 2026-10-07 Xcode 安装后补验

环境：Xcode 27.0（27A266a）、iOS / iPadOS 27.0；通过进程级 `DEVELOPER_DIR` 选择 Xcode，未修改全局开发工具选择。

- iOS 通用模拟器构建通过；指定 iPad mini (A17 Pro) 的构建、安装和启动通过。
- 修复 Debug 主工程同时链接 x86_64、Swift 包只构建 arm64 导致的指定设备链接失败，主工程使用当前架构；Release 保留全架构。
- 完整 Xcode 下 15 项核心测试通过。检查脚本修复系统 Bash 在空参数数组下的 `nounset` 错误，自动识别已安装 Xcode。
- iPhone 17e：新建 `验收/移动端.md`，打开源码、输入后点击保存、切换阅读、勾选任务并再次保存。Unicode（中文、emoji、组合字符）正文写回后逐字核对；其中 Unicode 由辅助功能填入并通过键盘编辑事件提交，此项不代表输入法组词验收。
- iPhone 17e：历史详情恢复为副本，磁盘验证恢复副本保留 `- [ ]`，原文件仍是 `- [x]`。
- iPhone 17e：通过键盘输入草稿标记，选择“保留恢复草稿并关闭”。核对私有草稿已落盘、Markdown 原文件不含标记；终止并重启应用后，通过设置找到该草稿并恢复副本。
- iPad mini：竖屏与横屏首页、标签导航和横屏阅读弹窗可见，标题、正文与操作菜单没有出现遮挡；未覆盖所有窗口尺寸与最大辅助字体。

本轮在模拟器应用沙盒中创建测试笔记，不使用个人库。未签名模拟器构建不等同于真机或发行签名验收。详细构建日志位于忽略的 `.build/`；可用 `./scripts/run-simulator.sh '<设备名称>'` 复现启动流程。

## 尚待验证

- 更多 iPhone 尺寸、iPad 窗口尺寸、长标题、搜索和键盘布局矩阵。
- 中文输入法：组合输入、取消、emoji、撤销/重做，切换前后台后的正文一致性。
- 真机上复验源码编辑、后台草稿、进程终止恢复及保存流程。
- 更完整的阅读代码、长链接、正文保真与源码切换矩阵（基础任务勾选已通过）。
- 导入 UTF-8 Markdown，同名拒绝覆盖；导出后检查字节及 `.md` 扩展名。
- 选择 iCloud Drive 文件夹 → 新建/修改 → 关闭重启 → 书签授权仍有效。
- 在桌面修改/删除已打开文件，移动端保存必须提示冲突；另存副本保留双方内容。
- 文件提供商断网、离线文件未下载、文件夹被移走、授权撤销等错误应可见。
- 删除 → 文件恢复 → 恢复为副本；同名原文件保持不变。
- 深色模式、动态字体、VoiceOver、外接键盘 Cmd+S。

## 兼容性边界

本版不是桌面完整语法渲染器，也未集成 WebDAV manifest 协议。基础索引在内存中保存正文，超大笔记库的性能尚未验证。不能用 macOS 共享页面编译或预览推断 iPhone 原生验收通过。
